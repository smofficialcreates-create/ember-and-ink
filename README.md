# Ember & Ink

A warm, literary book blog for self-help and fantasy romance readers. Built with **Astro 5**, **Tailwind CSS 4**, **TypeScript**, and Markdown content collections. Deploys to **Cloudflare Pages** with zero extra configuration.

- **Live site:** https://emberandink.com
- **Amazon Associates tag:** `shubhstor0de4-21` (set via env var)
- **Build:** fully static, no server runtime required

---

## Quick start

```bash
npm install
cp .env.example .env       # or create .env manually
npm run dev                # http://localhost:4321
